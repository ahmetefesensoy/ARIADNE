# Optional user-profile skills

These are selected copies of skills available in the original user's local Codex profile. They are not automatically activated from this directory. On the same user account they may already be installed; avoid duplicate copies with the same name. On another machine, install only the needed folders into that host's supported skill directory, preserving references and notices.

USER_SKILLS_INVENTORY.json lists the exact files and missing references. The shared ../references directory required by Blender Director and several specialist skills was already absent on the source machine. Copying these folders alone does not repair that missing dependency. Do not claim the whole Blender pipeline is ready until relevant references and actual Blender/editor tools are available.

No Codex config, credentials, plugin caches, paid subscriptions or editor/MCP processes are included. Preserve existing licence/copyright notices; inspect unclear source/licence details before public redistribution.
