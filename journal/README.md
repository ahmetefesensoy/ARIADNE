# Geliştirme günlüğü

Hackathon boyunca ne yapıldığının tarih sıralı kaydı. Her çalışma oturumu `log/` altında ayrı bir dosyadır (`YYYY-MM-DD-kısa-başlık.md`).

- [PROGRESS.md](PROGRESS.md): taş (T0–T14) bazında güncel durum
- [../docs/VERIFICATION_LOG.md](../docs/VERIFICATION_LOG.md): çalıştırılan komutlar ve gerçek test çıktıları
- [log/](log/): oturum notları

## Oturum notu şablonu

```
# YYYY-MM-DD — başlık
**Yapılanlar:** …
**Kanıt:** (test/komut/commit)
**Sorunlar / kararlar:** …
**Sıradaki:** …
```

Bir taş yalnız gözlenmiş kabul kanıtıyla "tamamlandı" yazılır.
