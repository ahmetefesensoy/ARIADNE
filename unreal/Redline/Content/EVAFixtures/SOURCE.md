# EV1 gameplay fixture sources

15 November 2026. This directory contains derived runtime assets imported by
`scripts/t5_prepare_eva_scene.py` and `scripts/t5_prepare_intro_content.py`.

The astronaut and idle/walk clips are existing Tripo outputs. Credit, generation
records and applicable terms remain in `assets/incoming/astronaut/SOURCE.md`
and `asset.json`. They are not relicensed CC0. No generation credits were spent
on this import/repair. Source textures and FBX files were not modified.
Locomotion root units were converted to the existing mesh bind scale; no new
character anatomy or motion capture was created.

Habitat: existing NASA-derived exterior, with its prior identifier-removal
revision and source notices in `assets/incoming/habitat/SOURCE.md`. Map table:
existing procedural package in `assets/incoming/map_table/SOURCE.md`. Context
station: existing Tripo package in `assets/incoming/science_station/SOURCE.md`.
All positions/use in this walkthrough are SCENARIO. No sampling location,
instrument result, habitat engineering rating or NASA endorsement is asserted.

The terrain retains the BXW data provenance from `docs/DATA_SOURCES.md` and
the T4 manifest. The return field is DERIVED from ROS/core, not painted or
generated by an image model. Original archive layers and scenario art remain
separate. Unreal Engine atmosphere and reflection assets retain Epic's terms.

See `docs/EVA_PLAYABLE.md` and `docs/verification/T5_ACCEPTANCE.json` for the
observed checks and limitations. A walkthrough of the exterior is not a
completed habitat interior, robot precursor mission or T8 science instrument.
